# Digit Classification

## Setup

- Create virtual environment
  - `python -m venv .venv`
- Activate virtual environment
  - `source .venv/bin/activate`
- Install dependencies
  - `pip install -r requirements.txt`
- Run `main.py` to train and test the model
  - `python main.py`
